# 🎬 Guess It! – Idioms & Slang Challenge

เกมทาย Idioms & Slang ภาษาอังกฤษจากอิโมจิ สำหรับบูธงาน ENGVENTURE

- 15 ชุดคำถาม ชุดละ 5 ข้อ ข้อละ 3 ตัวเลือก
- ตอบถูกได้ 1 คะแนน (เต็ม 5) ตอบผิดมีเฉลยพร้อมความหมาย
- ตอบถูก 3 ใน 5 ข้อขึ้นไป รับ Stamp

**เล่นได้ที่:** เปิด `index.html` ในเบราว์เซอร์ หรือผ่าน GitHub Pages ของ repo นี้

คีย์ลัด: `A/B/C` หรือ `1/2/3` = ตอบ · `Enter` = ข้อต่อไป · `F` = เต็มจอ
